## 인쇄용 파일

- **인쇄는 [`print/Lovable_전체_출력용.pdf`](print/Lovable_전체_출력용.pdf) 하나만 보면 됩니다.** (60쪽 · 16:9)
  - 구성: 표지 1쪽 + 본문 58장(앞단 1~25, 2부 26~58). 클릭으로 나오는 내용은 모두 펼친 상태입니다.
  - 조직문화 슬라이드는 2쪽(키워드 → THE CHALLENGE)으로 나뉘어 있어요.
  - 인쇄 설정: **가로 방향 · 페이지에 맞춤**. 한 장에 여러 슬라이드를 넣으려면 "용지당 페이지 수"에서 2 또는 4를 고르면 됩니다.
  - 화면 캡처(2배 해상도)로 만든 파일이라 글자 선택·복사는 안 돼요. 문구를 복사하려면 `index.html`을 여세요.
- `Lovable_앞단_출력용.pdf`, `Lovable_뒷단_출력용.pdf`는 이전 버전이에요. 인쇄에는 쓰지 마세요.
- `index.html?print`는 PDF를 다시 만들 때 쓰는 화면입니다. 인쇄용으로 직접 쓰지 마세요(그라데이션 글자 주위에 얇은 선이 생깁니다).
- 슬라이드를 고친 뒤에는 PDF도 다시 만들어야 해요. PR에 "인쇄용 PDF 갱신 필요"라고 적어 주세요.
